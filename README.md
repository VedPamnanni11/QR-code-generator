# QR-code-generator

This project generates a QR code from any text or website link using Python.

## What it does
- Takes text or a URL as input
- Creates a QR code image
- Saves it as a `.png` file (you can change the filename before saving)

## How to run it
1. Make sure you have Python installed.
2. Install the required library:
   ```bash
   pip install qrcode
   ```
3. Run the script:
   ```bash
   python main.py
   ```
4. When it asks, type the text or website you want in the QR code.
5. The QR code will be saved as `qrcode.png` (or whatever name you choose in the code).

## Notes
- Make sure you save the file with a `.png` extension.
- You can open the saved file in any image viewer or share it.
